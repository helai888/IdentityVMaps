# IdentityVMaps

Identity V map guide images (private).

- Phosphorescence (磷光症): 40 maps — 15 nightmare, 12 hard, 13 normal.
- Each map has 5 files: B1 feature, B2 feature, floor 1 map, floor 2 map, floor 3 map.
- Layout: `<difficulty>/<B1 folder>/<B2 stem><type>.jpg`
- B1 feature is shared per B1 folder (one per room shape); B2 feature is per map.
